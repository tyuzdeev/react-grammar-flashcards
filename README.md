# 🗂 React Grammar Flashcards

Интерактивное Single Page Application (SPA) на React для создания и изучения флеш-карточек. Отлично подходит для заучивания IT-терминов, иностранных слов или правил грамматики.

Проект разработан для демонстрации базовых, но ключевых концепций React: компонентного подхода, работы с внутренним состоянием и передачи данных через пропсы.

## 🚀 Функционал
- **Двусторонние карточки:** Клик по карточке плавно переворачивает её (CSS 3D Transform + React State), показывая определение.
- **Динамический список:** Добавление новых карточек через форму и мгновенный рендеринг.
- **Удаление:** Возможность удалить конкретную карточку (демонстрация фильтрации массива в стейте).

## 🛠 Стек технологий
- **React 18** (Functional Components)
- **React Hooks:** `useState` для управления вводом формы, состоянием переворота каждой карточки и общим списком данных.
- **Tailwind CSS:** для быстрой и адаптивной стилизации интерфейса.
- **Vite:** в качестве бандлера (сборщика) проекта.

## 💡 Особенности архитектуры
- Логика разделена на два компонента: главный `<App />` управляет массивом данных, а изолированный `<Flashcard />` отвечает за свой собственный UI (анимацию переворота) и принимает функцию удаления через `props`.
- Использование `Date.now()` для генерации уникальных ключей (keys) при рендеринге списков.

## 💻 Как запустить локально

1. Клонируйте репозиторий:
   ```bash
   git clone [https://github.com/tyuzdeev/react-grammar-flashcards.git](https://github.com/tyuzdeev/react-grammar-flashcards.git)
   cd react-grammar-flashcards
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите сервер для разработки:
   ```bash
   npm run dev
   ```
